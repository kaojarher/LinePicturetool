✂️ STEP 2｜裁切與去背

🔗 裁切工具網址（請用Safari or Chrome開啟，不要用IG內建視窗）： https://kaojarher.github.io/LinePicturetool/


⚠️ 注意事項： 本工具限 4×4 排列的貼圖母圖使用，每次處理”一張”母圖，自動裁切 16 格，處理完第一張可以上傳第二張母圖，全部可以一次儲存最多32張貼圖



▌ 使用步驟

步驟一：上傳母圖

點「選擇圖片」按鈕
上傳由 ChatGPT 生成的 4×4 貼圖一張母圖


步驟二：自動偵測貼圖

點「✦ 自動偵測貼圖」
工具會自動辨識 16 個格子並裁切，同時去除背景色
裁切結果會顯示在下方預覽區，選單要往下滑
可以點 ✕ 刪除不要的格子


步驟三：手動補裁（大部分情況不用）

若自動偵測有切錯或漏掉的格子，刪除貼圖之後，可用手指（或滑鼠）拖曳框選範圍
按「✂ 手動裁切並加入」補上
去背效果不理想的格子，也建議改用手動框選（也可以把去背關閉）


步驟四：上傳第二張母圖（選用）

最多可儲存 32 張貼圖（兩張母圖）
第一張處理完後，按「↑ 上傳下一張」匯入第二張母圖
兩張的結果會累積在同一個預覽區


步驟五：下載 ZIP

確認全部無誤後，點「⬇ 下載 ZIP」
打包下載所有透明背景 PNG 檔案
ZIP 檔案會儲存到手機儲存空間


🔄 重新開始： 若要清空所有內容重新開始，點「↺ 全部重來」即可



▌ iPhone 解壓縮並存入相簿

到檔案APP 找到並解壓縮 ZIP 檔案(檔案名應該叫做CropAlpha)
在解壓縮之後的資料夾，點選右上角「⋯」→ 選擇→ 全選
點「分享」→「儲存 16 個影像」到相簿

❓ 常見問題

Q：免費版 ChatGPT 可以用嗎？

✅ 可以！免費版 ChatGPT 支援圖片生成功能，不需要付費升級。


Q：照片要幾張？

建議上傳 1–6 張，角度越多元，生成效果越好。
清晰的正臉照效果最佳。


Q：裁切完的圖片尺寸符合 LINE 規定嗎？

裁切工具會自動處理去背，但建議送審前確認尺寸為 370×320px。
LINE 官方要求 PNG 格式、透明背景。


Q：上架後可以修改嗎？

審核通過後，貼圖內容無法修改。
可以修改價格或下架，但圖片需重新申請才能更換。
